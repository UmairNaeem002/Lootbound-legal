# Privacy Policy

Last updated: [DATE]

This Privacy Policy explains what data **Lootbound** collects and how it is used.

## Data We Collect

Lootbound may collect and store the following Discord-related data:

- Discord user IDs
- Discord server IDs
- Discord usernames or display names
- Game profile data
- Coins, gear, inventory, chests, materials, keys, and rewards
- Raid, PvP, quest, daily, and achievement progress
- Marriage status between users who use the marriage system
- Leaderboard statistics
- Command usage needed to operate bot features

Lootbound does not intentionally collect message content unless it is required for a command or interaction.

## How We Use Data

We use collected data to provide bot features, including:

- Player profiles
- Gear progression
- Raids and battles
- Chests and inventory
- Achievements and leaderboards
- Quests and daily rewards
- Marriage and wedding trial features
- Moderation of cheating, abuse, or exploits
- Bot maintenance and debugging

## Data Sharing

We do not sell user data.

Data may be processed through services required to run the bot, such as Discord and Firebase/Google Cloud.

We may disclose data if required by law, Discord policy, or to protect the bot from abuse, exploitation, or security issues.

## Data Storage

Lootbound stores bot data in Firebase Realtime Database.

Data is kept for as long as needed to provide bot features, maintain game progress, prevent abuse, or operate the bot.
